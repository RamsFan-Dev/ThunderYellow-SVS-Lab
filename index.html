04 • Pokémon manager

Party & PC Pokémon Editor

Edit existing Pokémon directly in your .svs: moves, current PP, PP Ups, experience, friendship, held items, IVs, EVs and battle stats. PC Pokémon may be copied, moved and deleted. The special starter Pikachu is protected from copying or deletion.

📋 Paste Pokémon sets (Showdown / PKMDS format)

Paste one or several complete Pokémon sets, separated by blank lines. Preview the party or PC destination before importing. Level defaults to 100 when omitted; IVs default to 31, and EVs default to 0. Optional SVS Lab lines: # PP: 35 / 40 / 99 / 0 and # PP Ups: 3 / 3 / 3 / 0 (four move slots; PP 0–99, PP Ups 0–3). Or use the one-tap 35/40 buttons.

Tap 35 or 40 to fill PP and 3 PP Ups for every nonempty move in the pasted sets. You can also type any current PP from 0–99 into the # PP: line. SVS Lab writes the requested value without a normal move-PP cap; the ROM may still change it during gameplay.
Complete party repair: Start with a fresh, verified in-game save state. Select Party / Slot 1 and paste up to six consecutive sets in party order. SVS Lab updates matching existing Pokémon, adds missing Pokémon into empty slots, preserves the original follower Pikachu's PID/OT, updates live RAM AND cartridge-save copies, and verifies the result before enabling export. Never applies unsafe flash-only edits.
Full Stats: Update an existing matching Pokémon: EVs, IVs, level/EXP, battle stats, held item, friendship, ability, and moves. Non-starter Pokémon can also change gender, nature, and shiny status. Original follower Pikachu keeps its fixed PID, nature, shiny status, and gender—differences from pasted values appear as explicit warnings before applying. This does not create missing party members.
Moves + Ability Only updates existing Pokémon moves, ability, current PP and PP Ups if supplied. Species must match. It preserves PID, OT, level, EXP, nature, shiny status, held item, IVs, EVs, happiness and follower identity. If PP / PP Ups lines are omitted, new moves get default PP and zero PP Ups.
Import is blocked if it would replace our special follower Pikachu, cross the party's six-slot limit, or skip an earlier empty party slot. PC batches can continue into the next box.
Starter shortcut finds your original follower Pikachu even when not in slot 1. Paste multiple Pokémon sets, but only Pikachu’s moves and listed ability will be imported. “Shiny: Yes” and every other set property will be ignored by this shortcut.
📤 Export Pokémon sets for Showdown / Notes

Create a copy-and-paste text list from Pokémon in your currently loaded, verified SVS. This is read-only and never edits the game, party, or save. The list includes levels, abilities, natures, shiny status, items, IVs, EVs, friendship, moves, current PP and PP Ups.

Values reflect saved Pokémon records, including 255-per-stat EVs.
