Report a problem in three steps

01 · CAPTURE

Save the problem

In Delta, export an .svs save state at the point where the bug occurs. Back up your regular in-game .sav separately.

02 · COMPRESS

Zip the .svs

Add the save state to a .zip archive. Optional screenshots help. Never include a copyrighted full .gba ROM.

03 · SUBMIT

Send the bug report

Include the exact test build, emulator, location, steps to reproduce, and expected behavior. Attach the .zip in the form.

What to include for a Pikachu follower glitch

For intermittent Surf or tracking problems, several save states from the same ROM build are more useful than a single late-state snapshot.

  • Before the problem (on land, following normally)
  • Surf entry and after swimming several tiles
  • After a battle, especially a wild encounter you escaped
  • The shore exit and moment Pikachu becomes unsynchronized

Privacy and compatibility: GitHub issue attachments may be publicly accessible when published in a public repository. Only upload saves you are comfortable sharing. Use the same ROM build when capturing and replaying an .svs. When testing new builds, start from a regular in-game .sav, not a previous build's .svs.
