What the first release will need

The public experience is designed around a local browser installer: players supply their own legitimately obtained Pokémon LeafGreen USA Rev 1 game, and receive a new ThunderYellow .gba after a verified first-release patch is published. This site does not distribute the Nintendo ROM.

Questions

Was ThunderYellow v1 already publicly released?

No. ThunderYellow v1 was an internal development build; a public first release has not occurred.

Can I download the game today?

No public ThunderYellow game version has shipped yet. Cover art is available now, and you can verify your own LeafGreen Rev 1 ROM with the browser installer.

What about Test 125N?

Test 125N was an internally gameplay-tested preview, not a public release. It does not establish that the overall game is complete or universally compatible.

Will the website distribute a complete .gba ROM?

The website will generate a complete ThunderYellow .gba locally from the user-supplied compatible LeafGreen original and a verified game patch when the first release is approved. It will not host or distribute Nintendo's original ROM.
