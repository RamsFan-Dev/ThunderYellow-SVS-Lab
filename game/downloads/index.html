How to apply the preview game update

Keep your original ROM and saves safe. This update is for existing v1 owners only.

STEP 01

Make a backup

Back up your existing ThunderYellow 2026 v1 GBA ROM and your normal in-game .sav. Do not overwrite the working ROM.

STEP 02

Apply the IPS patch

Use a trustworthy IPS-compatible patching tool. Select your original ThunderYellow v1 ROM as the source, then select the downloaded .ips file. Write a new ROM with a distinct filename.

STEP 03

Test in Delta

Import the updated ROM into Delta and load a compatible regular in-game save. Do not use an older build's .svs save state to judge the new build; cross-version states can be incompatible.

Frequently asked questions

Can I download a complete .gba ROM here?

No. This site supplies game modification patches and original project files; it does not distribute copyrighted commercial ROMs. The current patch requires an existing ThunderYellow v1 ROM.

Does Test 125N count as a final release?

No. It passed targeted Delta gameplay tests including certain follower, Surf and battle transitions. It is still a preview build and has not passed a complete regression/playthrough test.

Will my older Delta save state work?

Save states (.svs) are tied to the exact ROM build. Preserve your in-game .sav and do not assume old snapshots will load correctly after patching. Back up both before upgrading.

Can I report an issue and attach a broken save state?

Yes. Use the technical-support page and GitHub bug form. ZIP the .svs and remove any private information; issue attachments are public.
